# Security policy

Please do not disclose suspected vulnerabilities in a public issue.

Report them through the repository’s private
[security advisory form](https://github.com/anderson-webops/operationopportunity.jacobdanderson.net/security/advisories/new).
Include the affected route or workflow, reproduction steps, expected impact,
and any suggested mitigation. Do not include real credentials, student data,
or other personal information.

Supported security fixes are released on the current stable `v2.x` line.
